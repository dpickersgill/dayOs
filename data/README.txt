ski-areas-us.json.gz: every US ski area with its lifts and runs, for demos built on a visitor's own mountain (526 areas, built 2026-10-24).
Made by: node scripts/ski-areas-build.js data/ski-areas-us.json.gz   (needs the internet; run it in Cloud Shell)
Data from OpenSkiData / OpenSkiMap.org, (c) OpenStreetMap contributors (ODbL), Skimap.org, Who's On First, (c) Mapterhorn.
When the file is missing, the demo page falls back to asking the public Overpass map servers live.
